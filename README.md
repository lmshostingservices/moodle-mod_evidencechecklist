# Evidence Checklist (mod_evidencechecklist)

Practical observation checklists for Australian RTOs. Assessors mark each criterion S or NYS with one tap for every
context and occasion the unit requires, attach photo, video and audio evidence, record gap plans and sign off.
Students see their checklist update live. Every assessment produces a Practical Evidence Report and PDF for students,
validators and auditors.

## Acquisition and activation — 1.2.1

**One-time site unlock: 500 LMS Labs credits, or US$50 on Moodle Marketplace.**
These are alternative acquisition routes, not two payments. A Marketplace purchase recognised by LMS Labs grants access without a second credit debit.
There are **no ongoing AI usage charges**.

1. Install the plugin through Quick Links or Moodle's normal plugin installer.
2. In Quick Links → Plugins → Evidence Checklist, explicitly confirm the one-time 500-credit unlock; alternatively have your Marketplace purchase recognised.
3. Open Site administration → Plugins → Activity modules → Evidence Checklist. Central Config credentials are preferred; enter optional plugin-specific credentials only if Central Config is not configured.
4. Select **Check activation — no charge**. Installation, viewing settings and activation checks never purchase or debit credits.
5. Add Evidence Checklist to a course. Open the activity's **Report** for evidence and assessor reporting.

Only site activation is checked with LMS Labs; no assessment content, files or learner answers are sent for that check.
Creating, editing and assessing requires verified site access. Existing read-only views, standard backups and deletion remain available.
Compatibility declared by the supplied plugin is Moodle **4.4–5.3**; this declaration is not a claim of independent testing on every version.

No AI generation or ongoing AI usage charges. A free site-activation check connects to LMS Labs; assessment content and evidence stay in Moodle. The bundled ChatGPT prompt is used outside Moodle by the RTO.

## Requirements
Declared compatibility: Moodle 4.4 to 5.3, with a PHP version supported by the installed Moodle release.

## Install
Site administration > Plugins > Install plugins, upload `mod_evidencechecklist_v1.2.1.zip`, then complete the upgrade and check site activation.

## Quick start
1. Add an Evidence Checklist activity to a course.
2. Open Build checklist, copy the prompt, run it in ChatGPT with your unit, paste the result into Fast paste,
   Preview, then Import.
3. Check the Mapping report shows Mapping complete.
4. Open a student from the class list and start marking.
